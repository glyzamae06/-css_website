Building a strong foundation in computer systems servicing and information technology!

Welcome to the Computer Systems Servicing strand, where students develop technical expertise through hands-on training, industry-based standards, and real-world applications.

About Us

The Computer Systems Servicing (CSS) Strand of Calaca Senior High School develops students’ skills in computer hardware, software installation, networking, and basic troubleshooting. Through hands-on training, students gain practical knowledge aligned with industry standards, preparing them for TESDA certification, IT-related careers, or further studies in technology.

Accessories

  • System Unit

    The main box of the computer that holds and protects all internal components.

  • Monitor

    The screen that displays text, images, and videos from the computer.

  • Mouse

    An input device used to point, click, and navigate on the screen.

  • Keyboard

    An input device used to type text and commands.

  • Automatic Voltage Regulator

    Regulates voltage to protect the computer from power fluctuations.

  • Powersupply

    Converts electricity from the outlet into power usable by computer parts.

  • HDD

    A traditional storage device that uses spinning disks to store data.

  • ODD

    A drive used to read or write CDs and DVDs.

  • RAM (Random Access Memory)

    Temporary memory that stores data the computer is currently using for faster access.

  • ROM (Read-Only Memory)

    A permanent memory that stores essential instructions needed to start the computer; its contents are not easily changed and remain even when the power is off.

  • CPU (Central Processing Unit)

    The main processor of the computer that executes instructions, performs calculations, and controls overall system operations.

  • Cooling Fan

    Keeps the computer components cool to prevent overheating.

  • Motherboard

    The main circuit board where all computer parts are connected and communicate.

  • LAN Card (Network Interface Card)

    A hardware component that allows a computer to connect to a local network or the internet using a LAN cable.

  • Graphics Card (Video Card / GPU)

    A hardware component that processes and renders images, videos, and graphics, then sends them to the monitor for display.
